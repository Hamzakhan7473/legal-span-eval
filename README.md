## What is evaluated

| Model | Provider | Model ID |
|---|---|---|
| Gemini 2.5 Flash | Google | `gemini-2.5-flash` |
| GPT-5.4 mini | OpenAI | `gpt-5.4-mini` |
| Claude Sonnet 4.6 | AWS Bedrock | `us.anthropic.claude-sonnet-4-6` |

Model IDs and decoding settings live in [`configs/models.yaml`](configs/models.yaml).
The task: given a contract excerpt and a clause category, decide whether the clause is
present and, if so, quote the span that expresses it.

## Running new models *(Phase 2)*

1. Copy `.env.example` to `.env` and add the provider keys you need.
2. Add the model to `configs/models.yaml` and its prices to `configs/pricing.yaml`.
3. Run an experiment target (for example `make e1`). The runner prints the planned
   call count and estimated cost before making any paid call.

All responses are cached on disk by a hash of provider, model, prompt, and
parameters, so rerunning an experiment does not repeat paid calls.

## Reproducibility

- **Frozen data.** `data/eval_set/eval_set.jsonl` is byte-identical to the file the
  original runs evaluated; `tests/test_eval_set.py` checks its SHA-256.
- **Logged runs.** Every model call is appended to `data/runs/<run_id>/calls.jsonl`
  with a manifest recording the git SHA, config hash, eval-set hash, timestamp, and
  library versions *(Phase 1)*.
- **Pinned dependencies.** Exact versions are in `pyproject.toml`.

## Data and license

The evaluation set consists of 150 examples drawn from the
[Contract Understanding Atticus Dataset (CUAD) v1](https://huggingface.co/datasets/theatticusproject/cuad),
created by The Atticus Project and licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Only these 150 examples are
redistributed here.

**Changes made to CUAD:** we selected 6 of the 41 clause categories (the first six
alphabetically that have enough positive and negative examples), sampled 25 items per
category (12 with the clause present, 13 without), and truncated each contract to an
excerpt of about 8,000 characters. Details are in
[`configs/eval_set.yaml`](configs/eval_set.yaml) and
[`data/eval_set/MANIFEST.json`](data/eval_set/MANIFEST.json).

If you use the data, please also cite CUAD:

> Dan Hendrycks, Collin Burns, Anya Chen, and Spencer Ball. 2021. CUAD: An
> Expert-Annotated NLP Dataset for Legal Contract Review. arXiv:2103.06268.
